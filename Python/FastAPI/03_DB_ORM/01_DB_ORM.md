# 데이터베이스
> 데이터를 체계적으로 저장하고 관리하는 시스템

- 데이터의 지속성 보장
- 동시성 처리
- 검색 및 정렬 최적화
- 안전한 데이터 관리

<br>

### 관계형 데이터베이스
> 데이터를 테이블 형태로 저장하고, 테이블 간 관계를 정의하여 관리하는 방식

- 행 (row) : 데이터 한 건
- 열 (column) : 데이터의 개별 속성, `컬럼`으로 지칭
- 데이터 무결성 : 데이터가 의도치 않은 변경이나 손상, 오류없이 완전함을 보장하는 것
- 데이터 일관성 : 동일한 데이터가 어디에서 조회되더라도 항상 같은 값으로 유지되는 것
- SQL (Structured Query Language) : 저장된 데이터를 생성, 조회, 수정, 삭제할 때 사용하는 언어
- 쿼리 (query) : 데이터베이스에 수행할 작업을 SQL로 작성한 명령 하나하나

<br>

# ORM (Object Relational Mapping)

```python
# 쿼리를 직접 작성하는 방식
데이터베이스 구조가 변경되는 경우 SQL과 애플리케이션 코드 전반을 함께 수정해야 하는 문제가 있음
```

> ORM : 객체 지향 언어의 객체와 데이터베이스의 테이블을 연결해 주는 기술
1. SQL 작성량 감소
    - 반복적이고 복잡한 SQL을 작성할 필요 없음
2. 가독성과 유지보수성 향상
    - 핵심 로직 중심으로 구성
3. 데이터베이스 종족성 감소
    - 데이터베이스를 변경하더라도 대규모 SQL 수정 없이 설정 변경만으로 대응 가능
