# SQLAlchemy
> 데이터베이스 연동 라이브러리이자 ORM 도구

1. ORM 지원
    - 데이터베이스 테이블을 ORM 모델로 매핑해 객체 중심으로 데이터 처리
2. 유연한 구조
    - ORM + SQL 지원
3. 다양한 데이터베이스 지원
    - MySQL, PostgreSQL, SQLite 등 지원
4. 풍부한 기능 제공
    - 테이블 간 관계 설정, 쿼리 빌더, 트랜잭션 관리

## SQLAlchemy와 데이터베이스 연결

> engine : 데이터베이스와의 실제 연결을 관리하는 객체  
> session : ORM이 데이터베이스와 상호작용할 때 사용하는 작업 단위

1. 엔진을 생성하고, 그 엔진을 기반으로 세션을 생성
2. 세션을 통해 데이터를 생성, 조회, 수정, 삭제하며, 모든 변경 사항을 세션이 관리
3. 세션은 여려 요청이 함께 공유하는 대상이 아니므로 요청마다 독립적으로 생성
    - 동시 요청에도 데이터 충돌 방지
    - 안정성과 유지보수성 향상

<br>

```python
mysql+pymysql://사용자명:비밀번호@호스트:포트/데이터베이스명
```
