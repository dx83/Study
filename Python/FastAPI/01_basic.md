# FastAPI
> 서버 측 로직을 구현하기 위한 파이썬 웹 프레임워크  
> 백엔드 개발 도구

<br>

#### 타입 힌트를 이용한 데이터 검증
```python
def greeting(name: str) -> str:
    return f"Hello, {name}!"
# name: str     매개변수 name이 문자열
# -> str        반환값이 문자열
```

<br>

#### API 문서 자동 생성
> http://서버주소/docs      Swagger UI 열림  
> http://서버주소/redoc     ReDoc 열림  

<br>

#### 비동기 방식 지원
- 동기 방식 : 메시지를 보내고 답장이 올 때까지 대기
- 비동기 방식 : 메시지를 보낸 뒤 답장을 기다리는 동안 다른 곳과 대화 가능

<br>

| 프레임워크 | Flask | Django | FastAPI |
|---|---|---|---|
| 출시연도 | 2010 | 2005 | 2018 |
| 성격 | 마이크로 프레임워크 | 풀스택 프레임워크 | API 프레임워크 |
| 비동기 지원 | 없음<br>(별도 설정 필요) | 부분 지원<br>(ASGI 기반 설정 가능) | 기본 지원<br>(async/await) |
| 주요 활용 분야 | 소규모 웹서비스,<br>API 서버 | 대규모 웹 애플리케이션 | REST API, GraphQL,<br>고성능 마이크로서비스
| 대표 사례 | 핀터레스트, 링크드인(초기) | 인스타그램, 도어대시 | 마이크로소프트, 넷플릭스, 우버 |
