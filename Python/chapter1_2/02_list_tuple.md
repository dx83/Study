## 리스트 자료형
```python
리스트명 = [요소1, 요소2, 요소3, ...]

a = []
b = [1, 2, 3]
c = ['Life', 'is', 'too', 'short']
d = [1, 2, 'Life', 'is']
e = [1, 2, ['Life', 'is']]
```

- [-1] : 마지막 요솟값 불러오기
- [][] : 리스트안의 리스트 요솟값 불러오기

<br>

#### 리스트 슬라이싱
```python
a[1:4]    # a[1]부터 a[3]까지 (a[1]부터 4-1개)
a[19:]    # a[19]부터 끝까지
a[:17]    # a[0]부터 a[16]까지 (처음부터 17-0개)
a[:]      # 처음부터 끝까지
```

<br>

#### 리스트 연산
```python
# -, / 연산 없음
a = [1, 2, 3]
b = [4, 5, 6]
a + b   # [1, 2, 3, 4, 5, 6]

a * 3   # [1, 2, 3, 1, 2, 3, 1, 2, 3]

# 리스트 길이
len(a)  # 3

# 요소 삭제
del a[1]
a       # [1, 3]

a = [1, 2, 3, 4, 5]
del a[2:]
a       # [1, 2]

# append : 매개 변수를 리스트 맨 마지막에 추가
a.append([6, 7])
a       # [1, 2, [6, 7]]
```

- sort() : 리스트의 요소를 순서대로 정렬
- reverse() : 현재 리스트를 역순으로 뒤집어 준다.
- pop() : 리스트의 맨 마지막 요소를 반환하고 그 요소는 삭제
    - 매개변수가 있는 경우, 해당 인덱스의 요소를 반환하고 그 요소를 삭제

<br>

- count(매개변수) : 리스트 안에 매개변수의 값이 몇 개 있는지 그 개수를 반환

<br>

## 튜플 자료형
`tuple 은 몇가지 점을 제외하고 list와 거의 비슷`

```python
t1 = (1,)
t2 = 1, 2, 3

a = (1, 2, 3)
a = a + (4,)    # 새로운 튜플이 생성되고 그 값이 a 변수에 대입
a               # (1, 2, 3, 4)
```

> 튜플의 요솟값은 한 번 정하면 수정, 삭제를 할 수 없다.
