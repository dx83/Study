## 외부 라이브러리

> pip
- 파이썬 모듈이나 패키지 설치 도구
```python
pip install 내려받을_패키지             # 최신 버전 설치
pip uninstall 삭제할_패키지
pip install 내려받을_패키지==1.0.4      # 특정 버전 설치
pip install --upgrade 설치한_패키지     # 최신 버전으로 업그레이드
pip list                              # 설치한 패키지 목록
```

<br>

> pip 설치가 필요한 기타 도구
- Faker : 테스트용 가짜 데이터 생성 (영한 이름, 주소 등)
- sympy : 방정식 계산
